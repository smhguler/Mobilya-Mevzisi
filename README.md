# Mobilya Mevzisi

Mobilya Mevzisi, HTML5 Canvas ve JavaScript ile geliştirdiğim savunma ve yerleştirme odaklı bir oyun prototipidir.

## Proje Özeti
Oyuncu gece hazırlık yapar, odaya farklı işlevlere sahip mobilyalar yerleştirir ve gündüz gelen düşman dalgalarına karşı savunma kurar. Projede yerleştirme, ekonomi, loot, progression ve yetenek sistemleri üzerine çalıştım.

## Özellikler
- Grid tabanlı yerleştirme
- Aktif / pasif mobilya mantığı
- Savunma ve ekonomi odaklı sistemler
- Loot ve blueprint ilerleme yapısı
- Seviye ve yetenek sistemi
- Gün bazlı zorluk artışı

## Teknolojiler
- HTML5
- Canvas API
- JavaScript
